# Bouli - Lazy Scripts - v0.3.0

Script library for productivity.

### Creating links

```shell
make create
```

### Cleaning links

```shell
make clean
```

## Coding Tools

### Available Scripts

#### Create and Open Sandbox
```shell
bouli-sandbox
```

#### Delete Folder .venv and __pycache__ from the current folder to the 3rd step
```shell
bouli-garbage-collector
```

## Streaming Tools

### Make the boomerang video for interval

```sh
bouli-streaming-interval
```

### Make the song for background

```sh
bouli-streaming-background
```

### BS - Bouli Say:

```sh
bs <message-to-the-streaming>
```
> Update txt file for OBS.
